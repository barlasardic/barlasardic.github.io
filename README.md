# Barlas Ardıç Portfolio Website

A cyber-analog portfolio site for electronics & audio hardware engineering work. Styled after real PCB materials: solder mask, FR4 substrate, copper traces, silkscreen, and phosphor.

## Built with
- HTML5 + CSS (custom properties for dark/light theming)
- Tailwind CSS (CDN) with custom design tokens
- Vanilla JavaScript — hash-based SPA router (#/home, #/projects, #/project-1, #/project-2, #/lab)
- IBM Plex Mono + Phosphor icons + Google Fonts

## Features
- **Home** — signal-chain story: Input → Process → Output
- **Projects** — case studies for the 4 Step Sequencer (nano-synth) and myOS Kernel
- **Lab** — skills matrix: Systems Architecture, Languages, Audio, Applied Math
- Hash routing with back/forward support, keyboard navigation, dark/light toggle, audio demos
